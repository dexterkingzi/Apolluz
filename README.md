## Escopo do desenvolvimento

Este módulo contempla exclusivamente o desenvolvimento frontend do CRUD de clientes da plataforma Apolluz.

A implementação foi realizada utilizando HTML5, CSS3 e JavaScript puro, com foco na construção da interface, validação de informações e experiência do usuário.

### Responsabilidades do frontend

- Construção da interface de cadastro de clientes.
- Implementação de campos dinâmicos para Pessoa Física e Jurídica.
- Máscaras e validações de CPF, CNPJ e telefone.
- Validação dos dados preenchidos no formulário.
- Exibição de mensagens de erro e notificações Toast.
- Organização visual e responsividade da interface.

### Divisão de responsabilidades

O desenvolvimento do backend e a integração com o banco de dados são de responsabilidade de outro integrante da equipe.
